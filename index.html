WHAT IS THIS ASSIGNMENT?

Understanding CLA 3

The assignment is to implement a CI/CD pipeline for a simple Machine Learning model using GitHub Actions.

🎯 Assignment Objective

The objective is to create a small machine learning application and automate its development workflow. The model must load a dataset, train, make predictions and display its accuracy. Automated pytest tests are then executed through GitHub Actions.

✓
Build a simple ML model using scikit-learn.
✓
Train the model and make predictions.
✓
Display the model accuracy.
✓
Automatically test the project using pytest.

🔄 What Does CI/CD Mean?

Continuous Integration (CI) automatically checks the project whenever code is pushed to GitHub. It checks out the source code, prepares Python, installs dependencies, runs the ML program and executes the tests.

Continuous Deployment (CD) takes place after CI successfully passes. The project is then deployed through GitHub Pages.

01
Developer pushes code to GitHub.
02
GitHub Actions starts CI.
03
ML program and pytest run.
04
Only after CI passes, CD deploys.
